# IAM Lab – Screenshot Evidence

This folder contains screenshots documenting the verification and audit analysis of the Microsoft Entra ID offboarding process.

## Evidence Collected

- Security group membership removal verification
- Account disablement verification
- Audit log analysis of account disablement
- Audit log analysis of security group removal
- Audit log analysis of session revocation

## Security and Privacy

Personal account information and unnecessary identifiers have been redacted to protect privacy.

All activities were performed in a personal Microsoft Entra ID lab environment using a fictional test user.
